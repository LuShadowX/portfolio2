01About the project

The portfolio started as a static showcase: intro animation, about section, skills, certificates and projects. For this upgrade I added features that make it a real client-side application. Each one has a reason to exist on a portfolio rather than being a demo bolted on.

  • Repo index: every repository on my GitHub, fetched live from the GitHub REST API. It has a search box that understands filters like lang:python stars:>2, a card view and a sortable table view, and a "shelf" you can drag repositories onto. The shelf is saved in the browser.
  • Contact form: rebuilt with JavaScript and regular-expression validation, accessible error messages, a character counter, a spam honeypot and a draft that survives a page reload.
  • From the desk: live clocks in my time zone and the visitor's, an embedded OpenStreetMap of LPU, an opt-in "how far away are you?" check using the Geolocation API, and a custom audio player for a short voice note.
  • Engineering: SEO metadata and structured data, a skip link and keyboard support, an offline fallback for the API, a debug mode, and code split into ES modules.
